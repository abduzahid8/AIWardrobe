1. Conversational UI — Users type naturally ("what should I wear today?") instead of tapping through menus. Zero learning curve.
2. Visual-First Display — Every item is shown as a clean product image (background removed). Fashion is visual — reading descriptions would kill the experience.
3. Immediate Value Loop — Outfit suggestions appear on the homepage the moment you add even 2–3 clothes. You don't have to finish setup to see the magic. This is the "aha moment" hook.
4. Goal-Based Onboarding — Instead of a survey, the homepage ends with 5 tappable style goals ("Plan my outfits better", "Look professional at work"). One tap and the experience is personalized.
5. Avatar Try-On — Users see outfits on a body that looks like theirs before committing. Removes the #1 fear: "will this look good on me?"
6. Progressive Personalization — Every interaction trains the AI. The more you use it, the smarter it gets. This creates a habit loop that makes leaving feel like a real loss.

# Deferred features — launch freeze 2026-11-03

Only blockers, severe UX/retention findings, security/privacy/data loss, billing or major performance failures can interrupt this freeze. Every proposal needs observed user evidence and the minimal-change/flag/metric/rollout/result loop.

Defer: social network/public feed/community comments; marketplace rebuild; novelty AI providers; crypto/tokens; expanded gamification; design-system rewrite; backend framework replacement; microservices expansion. Advanced multimodal, autonomous stylist, proactive notifications, price watches, advanced VTON and experimental visual ranking remain off/internal until their own evidence, caps, fallback and control tests pass. Do not hold core beta for them unless a shared critical path depends on them.

Also defer until beta evidence: broader stylist automation, richer shopping integrations, new engagement campaigns, automated feedback uploads, complex analytics infrastructure and persistent correction synchronization. Revisit only when first value, repeat use, confusion, damaging mistakes and actual cost are understood. Existing user data and core correctness take priority over breadth.
